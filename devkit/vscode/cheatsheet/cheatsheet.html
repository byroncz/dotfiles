devkit: comandos

Generada de devkit/scripts/comandos.txt por gen-cheatsheet.sh. Ctrl+Shift+P → devkit: comandos la vuelve a abrir.

contenedor

devkit code <proyecto>
$ devkit code ventas

Abre el editor VS Code del proyecto en el navegador.

devkit shell <proyecto>
$ devkit shell ventas

Abre una shell dentro del contenedor.

devkit recreate <proyecto>
$ devkit recreate ventas

Recrea los contenedores, reconstruyendo solo las capas que cambiaron.

devkit rebuild <proyecto>
$ devkit rebuild ventas

Reconstruye las imágenes desde cero y recrea.

devkit awake <proyecto>
$ devkit awake ventas

Impide que el Mac se suspenda mientras el contenedor esté vivo.

agentes

devkit-run --estado --seguir
$ devkit-run --estado --seguir

Muestra todos los agentes del contenedor y se refresca cada 3 s. Úsalo para saber qué está corriendo; Ctrl-C cierra solo el monitor.

devkit-run --tablero --seguir
$ devkit-run --tablero --seguir

Muestra las cards activas del proyecto en una tabla y se refresca cada 30 s.

devkit-run --seguir <skill> <Clave>
$ devkit-run --seguir task-start DEVKIT-42

Lanza una skill en segundo plano y se queda mostrando su avance hasta que termina.

devkit-run pr-review <N>
$ devkit-run pr-review 42

Revisa el PR número `<N>` como revisor independiente y publica el veredicto.

devkit-run task-fix <N>
$ devkit-run task-fix 42

Corrige el PR número `<N>` según los hallazgos de la última revisión.

cards

task-close.sh <Clave> [PR]
$ task-close.sh DEVKIT-42 118

Cierra una card mergeada: `Estado` a `Hecha` y marcador en el PR.

task-block.sh <Clave> <motivo>
$ task-block.sh DEVKIT-42 "Qué intenté: ... Qué necesito: ..."

Bloquea una card y anota el motivo.

devkit-net-denied
$ devkit-net-denied

Lista los dominios que el proxy rechazó recientemente.

Python

uv add <paquete>
$ uv add polars

Agrega una dependencia al proyecto y la fija en `pyproject.toml`.

uv sync
$ uv sync

Instala en el entorno del proyecto exactamente las dependencias de `pyproject.toml`.

uv run <comando>
$ uv run python etl.py

Corre un comando dentro del entorno del proyecto, sin activarlo a mano.
