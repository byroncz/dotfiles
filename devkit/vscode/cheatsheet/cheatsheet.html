devkit: comandos

Generada de devkit/scripts/comandos.txt por gen-cheatsheet.sh. Ctrl+Shift+P → devkit: comandos la vuelve a abrir.

contenedor

devkit code <proyecto>
$ devkit code ventas

Abre el editor VS Code del proyecto en el navegador. Úsalo para el trabajo del día a día.

devkit shell <proyecto>
$ devkit shell ventas

Abre una shell dentro del contenedor. Úsalo para depurar o correr un comando suelto sin abrir el editor.

devkit recreate <proyecto>
$ devkit recreate ventas

Recrea los contenedores, reconstruyendo solo las capas que cambiaron. Úsalo tras tocar .devkit/devkit.toml o, en modo dev, el propio devkit/. Se niega si hay un agente en curso; --force salta la guarda.

devkit rebuild <proyecto>
$ devkit rebuild ventas

Reconstruye las imágenes desde cero y recrea. Úsalo cuando cambies el Dockerfile o sospeches que la imagen quedó corrupta; recreate no alcanza. Misma guarda de agentes en curso que recreate.

devkit awake <proyecto>
$ devkit awake ventas

Impide que el Mac se suspenda mientras el contenedor esté vivo. Úsalo antes de un lanzamiento largo sin supervisión, para que el Mac no lo corte al dormirse.

agentes

devkit-run --estado [--seguir]
$ devkit-run --estado --seguir

Muestra todos los agentes del contenedor y se refresca cada 3 s. Úsalo para saber qué está corriendo; Ctrl-C cierra solo el monitor.

devkit-run --tablero [--seguir]
$ devkit-run --tablero --seguir

Muestra las cards activas del proyecto en una tabla y se refresca cada 30 s. Úsalo para ver de un vistazo qué card está en progreso o bloqueada.

devkit-run <skill> <Clave>
$ devkit-run --seguir task-start DEVKIT-42

Lanza una skill en segundo plano y se queda mostrando su avance hasta que termina. Úsalo para lanzar cualquier skill a mano, fuera del ciclo automático del bucle.

devkit-run pr-review <N>
$ devkit-run pr-review 42

Revisa el PR número <N> como revisor independiente y publica el veredicto. Úsalo para forzar una revisión sin esperar al bucle.

devkit-run task-fix <N>
$ devkit-run task-fix 42

Corrige el PR número <N> según los hallazgos de la última revisión. Úsalo para forzar una corrección sin esperar al bucle.

cards

task-close.sh <Clave> [PR]
$ task-close.sh DEVKIT-42 118

Cierra una card mergeada: Estado a Hecha y marcador en el PR. Úsalo tras mergear a mano, cuando el bucle no la alcanzó a cerrar solo.

task-block.sh <Clave> <motivo>
$ task-block.sh DEVKIT-42 "Qué intenté: ... Qué necesito: ..."

Bloquea una card y anota el motivo. Úsalo cuando falte algo del humano y no puedas seguir sin preguntar.

devkit-net-denied
$ devkit-net-denied

Lista los dominios que el proxy rechazó recientemente. Úsalo cuando una conexión falle con "connection refused", para saber qué dominio falta en la lista blanca.

Python

uv add <paquete>
$ uv add polars

Agrega una dependencia al proyecto y la fija en pyproject.toml. Úsalo para instalar una librería nueva.

uv sync
$ uv sync

Instala en el entorno del proyecto exactamente las dependencias de pyproject.toml. Úsalo tras cambiar de rama o editar pyproject.toml a mano.

uv run <comando>
$ uv run python etl.py

Corre un comando dentro del entorno del proyecto, sin activarlo a mano. Úsalo para ejecutar un script o una prueba puntual.
